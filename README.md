# Purpose
This README ensures that only the Python notebook is executed.
All LaTeX files (.tex) in the project are ignored. The notebook
produces all figures, tables, and numerical results used in the
manuscript and E-companion.

# Execution Workflow

step: 1
dockerfile: Dockerfile.python
description: >
  Execute the Jupyter notebook located at:
  data/data/Code_On_the_Expansion_of_Risk_Pooling.ipynb
  All outputs are saved in the `99_logs/` folder.
notes: >
  The notebook is executed automatically using:
  `jupyter nbconvert --to notebook --execute`
  Monte Carlo simulations are used; minor variations may occur.
  LaTeX compilation is NOT performed in this workflow.

# Dockerfile Rules
- Only Dockerfile.python should exist in the project root.
- Rename or remove any other Dockerfile (especially LaTeX Dockerfile):
  `mv Dockerfile Dockerfile.latex-backup`
- Automated systems should use: 
  `docker build -t test4-python -f Dockerfile.python .`
  `docker run --rm -v $(pwd)/99_logs:/app/99_logs test4-python`
