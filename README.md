# Project Name
On_the_Expansion_of_Risk_Pooling

# Authors
Michail Anthropelos, Runhuan Feng, Seongyoon Kim

# Purpose
This README is dedicated to executing only the Python notebook
for generating all figures, tables, and numerical results
used in the manuscript and E-companion. LaTeX compilation
is explicitly excluded.

# Execution Workflow

step: 1
dockerfile: Dockerfile.python
required: true
description: >
  Execute the main Jupyter notebook located at:
  data/data/Code_On_the_Expansion_of_Risk_Pooling.ipynb.
  All outputs (executed notebook, figures, tables) are saved in the `99_logs/` directory.
notes: >
  The notebook is executed automatically with `jupyter nbconvert --execute`.
  Monte Carlo simulations are used. Random seeds are not fixed,
  minor variations may occur, but results remain consistent.
  LaTeX files (.tex) are ignored in this workflow.

# Dockerfile Rules
- Only Dockerfile.python should exist in the project root.
- Delete or rename any default Dockerfile or LaTeX Dockerfile:
  `rm Dockerfile` or `mv Dockerfile Dockerfile.latex-backup`.
- Automated systems must use `-f Dockerfile.python` to build/run.
