# Purpose
This README is dedicated to executing only the Python notebook for
generating all figures, tables, and numerical results used in the
manuscript and E-companion. LaTeX compilation is explicitly excluded.

# Project Structure
notebook_folder: analysis
description: >
  All Python code, the main notebook, and required data are now
  located in the folder `analysis`. LaTeX files are ignored in this workflow.

# Execution Workflow

step: 1
dockerfile: Dockerfile.python
required: true
description: >
  Execute the main Jupyter notebook located at:
  analysis/Code_On_the_Expansion_of_Risk_Pooling.ipynb
  Outputs (executed notebook, figures, tables) are saved in `99_logs/`.

notes: >
  The notebook is executed automatically with:
  `jupyter nbconvert --to notebook --execute`.
  Monte Carlo simulations are used; minor variations may occur.
  All outputs are deterministic except for Monte Carlo results.

# Dockerfile Rules

- Automated systems must use `-f Dockerfile.python` to build/run.
- LaTeX Dockerfiles (if present) should be renamed or removed:
  `mv Dockerfile Dockerfile.latex-backup`
